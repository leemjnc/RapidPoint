RapidPoint 1.11.5
대상 창 자동 활성화 좌표 바인딩 및 다중 복합 연타 매크로 (Windows 10/11, 64비트)

[자동 활성화]
1. 메인 화면에서 "창 목록에서 선택"을 누릅니다.
2. OBS처럼 현재 열려 있는 창 목록에서 사용할 프로그램이나 에뮬레이터를 선택합니다.
3. 원하는 창이 보이지 않으면 "새로 고침"을 누릅니다.
4. 연결한 대상 창이 전면에 있을 때만 모든 바인딩과 매크로 실행 키가 자동으로 활성화됩니다.
5. Codex나 다른 창으로 전환하면 진행 중인 반복이 즉시 중지되고 할당 키도 감지하지 않습니다.
6. 대상 창으로 돌아가면 자동으로 다시 활성화됩니다.

[퍼즈 스킬: 키 하나로 실행]
1. 새 매크로를 추가하고 실행 키(예: X)를 정합니다.
2. 설정창 하단의 모드 목록에서 "퍼즈 스킬 · ESC+키 → 클릭"을 선택합니다.
3. 1단계에 ESC와 함께 누를 스킬 키(예: 2)를 지정합니다.
4. 2단계에서 클릭할 저장 좌표 또는 현재 마우스 위치를 선택합니다.
5. "클릭 후 ESC 재정지"를 켜면 스킬 사용 후 다시 일시정지 입력을 보냅니다.
6. 게임을 일시정지한 상태에서 실행 키를 한 번 누릅니다.
7. ESC+스킬 키 누름 → 두 키 해제 → 좌클릭 → 선택적으로 ESC 순서로 한 번 실행합니다.
이 모드의 2단계는 좌클릭입니다. 현재 위치는 실행 키를 누른 시점의 커서 위치를 사용합니다.
저장 좌표는 클릭 시점의 대상 창 위치와 크기로 보정합니다.
누름 유지, 클릭 전 대기, 재정지 전 대기를 각각 조절할 수 있습니다.
기본 10ms는 조정용 초기값이며, 무손실 프레임이나 게임의 입력 수신을 보장하지 않습니다.
게임의 일시정지 여부·코스트·스킬 성공 여부는 자동 판독하지 않습니다.
한 번 실행 중에는 다른 매크로·바인딩과 섞이지 않도록 새 입력을 받지 않습니다.
대상 창을 벗어나면 실행을 중단하고 눌린 키·버튼을 해제합니다.
1.11.0부터 퍼즈 전용 실행 스레드와 고정밀 대기 타이머를 사용합니다.
설정된 누름 유지/대기 시간을 임의로 줄이거나 앞 단계 지연을 만회하려고 뒷 단계를 압축하지 않습니다.
참고한 수동 조작 설명:
https://gall.dcinside.com/mgallery/board/view/?id=projectmx&no=19133277

[퍼즈 반복: 클릭과 ESC를 교대로 입력]
1. 새 매크로에 별도의 실행 키를 지정합니다.
2. 하단 모드 목록에서 "퍼즈 반복 · 클릭 → ESC" 또는 "퍼즈 반복 · ESC → 클릭"을 선택합니다.
3. 2단계에는 퍼즈 메뉴의 게임 복귀 버튼 위치를 지정합니다. 스킬을 겨냥하는 좌표와 구분하세요.
4. "클릭 → ESC"는 일시정지 상태에서 복귀 버튼 클릭 → ESC 재정지 순서입니다.
   "ESC → 클릭"은 플레이 중 ESC로 메뉴 열기 → 복귀 버튼 클릭 순서입니다.
   실제 게임 메뉴가 해당 위치의 클릭으로 복귀하는지 먼저 한 번 실행하여 확인하세요.
5. 반복 방식은 "누르는 동안 무제한", "토글로 무제한", "지정 횟수 실행" 중 선택합니다.
   처음에는 지정 횟수 1회로 순서와 좌표를 확인한 뒤 누르는 동안 반복으로 바꾸세요.
6. 누름 유지는 각각의 키/마우스 버튼을 누른 상태로 유지하는 시간입니다.
   클릭 → ESC에서는 "재정지 전 대기", ESC → 클릭에서는 "클릭 전 대기"가 두 입력 사이의 시간입니다.
7. 이 모드에서 위쪽 "입력 간격"은 한 묶음이 끝난 후 다음 묶음까지의 대기입니다.
   작업이 늦어져도 밀린 입력을 한꺼번에 따라잡아 보내지 않습니다.
8. 현재 위치를 선택하면 시작 시점의 커서 위치를 반복 사용합니다.
   창 이동/크기 변경을 따라가려면 창 비례 좌표로 저장한 바인딩을 선택하세요.
9. 키를 놓거나 토글을 끄면 진행 중인 한 묶음을 끝내고 반복을 중지합니다.
   다른 창으로 이동하거나 프로그램을 종료하면 안전을 위해 즉시 취소하고 눌린 입력을 해제합니다.
   안전 취소 후 게임이 정지/진행 중 어느 상태일지는 보장하지 않습니다. 화면을 확인하세요.
퍼즈 반복 중 다른 매크로나 바인딩은 시작하지 않습니다. 멈춘 뒤 스킬 매크로 키를 새로 누르세요.
기본 시간은 조정용이며, 카드 갱신 가속이나 0.033초 기록을 보장하지 않습니다.

[ESC + 지정 키: 클릭 없는 동시 입력]
1. 하단에서 "ESC+지정 키 · 동시 입력만"을 선택합니다.
2. 1단계에 게임에서 실제 사용하는 AUTO 등의 키를 지정합니다.
3. 실행 키를 한 번 누르면 ESC와 지정 키를 함께 누르고 해제합니다. 마우스 입력은 보내지 않습니다.
이 모드도 게임의 정지/AUTO 상태를 판독하거나 성공 여부를 확인하지 않습니다.

위 모드는 사용자가 제공한 글의 입력 순서를 재현합니다.
https://arca.live/b/bluearchive/182094813
FPS, VSync, 모니터 주사율, Windows 마우스 키 설정은 자동 변경하지 않습니다.
Windows 마우스 키를 켜지 않아도 프로그램이 마우스 클릭 입력을 전송합니다.
여러 EX의 자동 연계, 카드/코스트 인식, 프레임 기준 동기화 기능은 포함하지 않습니다.

[새로운 좌표 키 바인딩 추가]
1. "+ 새 바인딩"을 누릅니다.
2. 별도의 "좌표 바인딩 설정" 창에서 이름과 할당 키를 정합니다.
3. 마우스 동작, 클릭 버튼과 실행 방식을 선택합니다.
4. X/Y를 직접 입력하거나 "좌표 입력"을 누릅니다.
5. 연결된 대상 창이 자동으로 복원되고, 창 내부에 반투명 좌표 선택 화면이 표시됩니다.
6. 원하는 지점을 좌클릭하면 기존 바인딩 설정창이 그대로 다시 나타납니다.
7. 클릭한 X/Y와 현재 창 크기가 설정창에 즉시 반영되므로 내용을 확인하거나 수정한 뒤 저장합니다.
8. 시간 제한은 없습니다. 취소하려면 Esc를 누릅니다.
9. 좌표 입력으로 저장하면 현재 창 크기가 기준 해상도로 자동 기록됩니다.
10. 이후 대상 창이 이동하면 새 창 위치를 따라가고, 크기가 바뀌면 가로·세로 비율로 좌표가 자동 보정됩니다.

[게임 중 실시간 좌표·안내선·클릭 보기 (1.11.4)]
1. 대상 창을 연결하고 메인 화면 키 바인딩 아래의 "게임 위 좌표 보기"를 켭니다.
2. 게임으로 돌아가면 게임 화면 왼쪽 위에 현재 마우스 좌표가 표시됩니다.
3. 위쪽 하늘색 제목의 "마우스 위치 · 창 좌표"는 제목 표시줄과 테두리를 제외한 창 내부 좌표입니다. 큰 숫자 아래에 현재 창 크기를 따로 표시합니다. "좌표 입력"으로 새로 찍을 때와 같은 좌표/현재 창 크기를 사용합니다.
4. 기존 바인딩의 X/Y를 수정하려면 메인 목록에서 해당 바인딩을 선택하세요. 아래쪽 노란 제목의 "바인딩 이름 · 설정 입력용"에 해당 바인딩의 기준 해상도로 환산한 X/Y와 저장 기준 크기가 표시됩니다.
   예: 현재 창 1600×900의 (800,450)은 기준 1280×720인 바인딩에서는 (640,360)입니다.
   위쪽 창 좌표 값을 복사하는 경우에는 기준 너비/높이도 함께 표시된 현재 창 크기와 맞추세요.
5. 화면 절대 좌표 바인딩을 선택하면 설정 입력용 영역에 화면 좌표가 표시됩니다. "현재 위치" 바인딩에는 저장 좌표가 없습니다.
6. 마우스 중심에 하늘색 가로·세로 안내선이 교차합니다. 화면 전체를 덮는 반투명 배경은 없으며 글자·선·표시 이외의 게임 색감은 그대로 유지합니다. 표시 위에서도 클릭은 게임으로 통과합니다.
7. 좌표를 표시할 뿐 클릭으로 저장하지 않으며, 게임 포커스를 가져오지 않습니다. 창 이동/크기 변경도 따라갑니다.
8. 다른 창으로 전환하거나 좌표 설정창을 열면 숨겨지고, 게임으로 돌아가면 다시 표시됩니다. 끄려면 같은 옵션을 해제하세요.
9. 독점 전체 화면 환경에서는 일반 창 오버레이가 보이지 않을 수 있습니다. 이 경우 창 모드나 테두리 없는 창 모드를 사용하세요.
10. 클릭한 위치에는 빨간 원과 십자 표시가 약 0.8초 동안 남습니다. 연타 때는 최근 8개까지 표시하며, 좌표 보기 모드를 끄면 모두 지워집니다.
11. 직접 누른 좌/우/가운데/보조 버튼과 Windows에서 감지된 매크로 클릭을 함께 표시합니다. 마우스 이동이나 버튼을 떼는 동작은 새 클릭으로 표시하지 않습니다.
12. 빨간 표시는 클릭 누름 이벤트를 감지했다는 뜻이며, 게임이 스킬을 발동했거나 입력을 처리했다는 보장은 아닙니다. 클릭 위치는 파일에 기록하지 않습니다.
13. 1.11.5부터 가로·세로 안내선은 테두리 없는 1픽셀 선입니다.
14. 왼쪽 아래 "최근 클릭 · 창 좌표"에는 마지막 클릭 한 건만 표시합니다. 다음 클릭으로 덮어쓰기 전까지 유지되며, 클릭 당시의 창 내부 X/Y와 창 크기를 표시합니다. 마우스 이동이나 이후 창 크기 변경으로 이 값이 바뀌지 않습니다.
15. 최근 클릭은 다른 창으로 잠시 전환해도 같은 게임으로 돌아오면 다시 보입니다. 좌표 보기를 끄거나 대상 창을 바꾸면 지워집니다. 직접 클릭과 매크로 클릭 모두 같은 방식으로 갱신합니다.

[마우스를 이동하지 않고 클릭]
1. 바인딩 설정창의 좌표 방식에서 "현재 위치 (이동 없음)"을 선택합니다.
2. 한 번 실행을 선택하면 키를 누를 때 현재 마우스 위치를 한 번 클릭합니다.
3. 누르는 동안 누름 유지를 선택하면 커서를 직접 움직이는 동안 마우스 버튼이 계속 눌린 상태로 유지됩니다.
4. 키를 놓을 때 클릭을 선택하면 "현재 위치" 방식에서는 커서를 이동하지 않고 키를 놓는 순간 현재 위치를 클릭합니다.

[바인딩 실행 방식]
- 한 번 실행: 키를 누르는 순간 지정 좌표 동작을 한 번 실행합니다.
- 누르는 동안 누름 유지: 키를 누르는 순간 지정 좌표로 한 번 이동하고 마우스 버튼을 누릅니다. 키를 놓으면 마우스 버튼도 놓습니다. "현재 위치"에서는 커서를 이동하지 않습니다.
- 키를 놓을 때 클릭: 키를 누르는 순간 지정 좌표로 이동합니다. 누르는 동안 마우스를 다른 곳으로 움직여도, 키를 놓는 순간 지정 좌표로 다시 이동한 뒤 클릭합니다. "현재 위치" 방식은 놓는 순간의 현재 위치를 클릭합니다.

프레임에 맞춰 클릭하려면 "키를 놓을 때 클릭"을 선택하고 클릭 버튼을 좌클릭으로 설정하세요.

[여러 연타 매크로 만들기]
1. 연타 매크로 영역에서 "+ 새 매크로"를 누릅니다.
2. 이름과 실행 키를 지정합니다. 각 매크로는 서로 다른 실행 키를 사용합니다.
3. "1단계 입력"을 켜고 키보드 키 또는 마우스 클릭을 선택합니다.
4. 마우스 클릭을 선택하면 좌클릭, 우클릭, 중클릭 중 하나를 정합니다.
5. "2단계 · 좌표 동작"을 켜고 현재 마우스 위치 또는 저장된 좌표 바인딩을 선택합니다.
6. 입력 간격, 반복 방식과 반복 횟수를 정하고 저장합니다.
7. 같은 방식으로 매크로를 계속 추가할 수 있습니다.

[일반 연타: 마우스 클릭 → 저장 좌표 동작 → 원래 위치 복귀 (1.11.3)]
- 1단계가 마우스 클릭이고 2단계가 켜져 있으면 "클릭 보호 적용"이 자동 활성화됩니다. 기존에 안정 입력을 껐던 설정에도 적용됩니다.
- 매 반복 시작 시 마우스 위치 A를 기억합니다. A에서 클릭 → 단계 간 대기 → 바인딩 위치 B로 이동 및 설정된 동작 → 대기 → A로 복귀 순서입니다.
- 다음 반복은 다시 A에서 클릭합니다. 반복 사이에 마우스를 직접 움직이면 그 새 위치가 다음 반복의 A가 됩니다.
- 바인딩이 "이동"이면 B로 이동만 하고, "클릭"이면 B에서 클릭까지 한 뒤 돌아옵니다. 복귀 자체는 클릭을 추가하지 않습니다.
- 누름 유지와 1→2단계 대기는 각각 최소 20ms입니다. 더 느린 값으로 설정했다면 그 값을 유지합니다.
- 다음 좌표로 너무 빨리 이동하거나 누름/해제를 동시에 보내 첫 클릭이 누락되는 위험을 줄입니다. 반복 속도는 이전보다 낮아질 수 있습니다.
- 실제 게임의 프레임률/입력 처리에 따라 더 긴 시간이 필요할 수 있습니다. 20ms는 무손실을 보장하는 값이 아니며 필요하면 30~50ms로 조절해 확인하세요.
- 2단계 동작 후 복귀 전에도 "1→2단계 대기" 값만큼 기다립니다. 2단계 클릭을 즉시 다른 위치로 옮기지 않기 위한 간격입니다.
- 실행 키를 놓으면 진행 중인 묶음의 복귀까지 마치고 멈춥니다. 다른 창으로 전환하거나 종료하면 즉시 취소하므로 추가 복귀 이동은 하지 않습니다.

[일반 연타: 1단계 키 바인딩 연계 (1.11.1)]
- "1단계 키 바인딩 적용"이 켜져 있고 해당 키에 활성 바인딩이 있으면, 그 바인딩의 좌표 동작을 먼저 실행한 뒤 2단계 동작을 실행합니다.
- 예: Q에 스킬 카드 좌표를 지정하고 X 매크로를 [Q → 현재 마우스 위치]로 설정하면, X 실행 시 Q의 좌표 클릭 → 원래 마우스 위치 클릭 순서로 동작합니다.
- 2단계가 현재 위치이면 매 반복의 1단계 이동 직전 커서 위치를 사용합니다. 저장 좌표이면 해당 좌표를 사용합니다.
- 바인딩의 "키를 놓을 때 클릭"이나 "누르는 동안 누름 유지"도 매크로 안에서는 한 번의 누름/해제 동작으로 완료합니다. 별도의 실제 Q 키 해제를 기다리지 않습니다.
- Q 좌표 동작 대신 게임에 Q 키 자체를 보내려면 "1단계 키 바인딩 적용"을 끄세요. 일치하는 활성 바인딩이 없으면 옵션과 관계없이 키 자체를 보냅니다.
- 퍼즈 스킬 모드는 이 옵션을 사용하지 않고 기존처럼 실제 스킬 키를 보냅니다.

[일반 연타: 안정 입력]
- 설정창 하단의 "안정 입력 (권장)"이 기본으로 켜집니다. 기존 설정에 이 옵션이 없을 때도 켜집니다.
- 1단계 키/버튼 누름 → 누름 유지 → 해제 → 1→2단계 대기 → 좌표 이동 → 2단계 클릭 누름 → 유지 → 해제 순서입니다.
- 누름 유지(기본 10ms)와 1→2단계 대기(기본 10ms)를 설정창에서 조절할 수 있습니다.
- 키/마우스를 누르자마자 같은 요청 안에서 해제하던 방식을 피하지만, 게임 입력 수신을 보장하는 것은 아닙니다.
- 반복 간격은 모든 모드에서 한 묶음을 마친 후 다음 묶음까지의 대기입니다. 밀린 입력은 몰아서 전송하지 않습니다.
- 따라서 안정 모드는 기존 일괄 전송보다 반복 횟수/초가 낮아질 수 있습니다. 안정성을 위해 의도한 변경입니다.
- "안정 입력"을 끄면 누름 유지/단계 대기가 적용되지 않습니다. 키 자체는 기존 일괄 전송을 사용하고, 1단계 바인딩을 적용하면 바인딩 동작 → 2단계 동작 순서로 전송합니다.
- 키를 놓거나 토글을 끄면 진행 중인 한 묶음을 완료하고 멈춥니다. 아직 시작하지 않은 묶음은 보내지 않습니다.
- 창 이탈/종료는 즉시 취소가 우선입니다. 눌린 키/버튼은 finally 정리에서 해제를 시도합니다.
- Windows 입력 전송이 일부만 성공하면 해제를 시도하고 오류를 표시하며 멈춥니다. 중복 스킬 방지를 위해 누름을 무조건 재전송하지 않습니다.
- 일반 연타의 기존 키, 좌표, 반복 횟수는 유지됩니다. 퍼즈 스킬의 기존 유지/대기 값도 유지됩니다.

예시
- X를 누르는 동안 [키 1 → 현재 마우스 위치 좌클릭] 반복
- Z를 누르는 동안 [키 2 → 공격 버튼 좌표 클릭] 반복
- C를 누르는 동안 [현재 위치 좌클릭 → 공격 버튼 저장 좌표 동작] 반복

1단계가 마우스 클릭이면 2단계의 "현재 마우스 위치 클릭"과 현재 위치형 바인딩은 목록에서 제외됩니다.
마우스 직접 입력 → 마우스 직접 입력 조합은 사용할 수 없고, 마우스 클릭 → 저장된 좌표 동작 조합만 허용됩니다.

일반 연타는 여러 실행 키를 동시에 누를 수 있지만, 한 묶음씩 순차 실행하여 키/좌표 동작이 서로 섞이지 않게 합니다.
매크로가 진행되는 동안 별도 바인딩 입력은 받지 않습니다. 누름 유지 바인딩을 먼저 놓고 매크로를 시작하세요.
퍼즈 모드는 입력이 서로 섞이지 않도록 다른 매크로와 동시에 실행하지 않습니다.

[반복 방식]
- 누르는 동안 무제한: 실행 키를 누르는 동안 반복하고 놓으면 현재 묶음을 완료한 뒤 중지합니다.
- 토글로 무제한: 실행 키를 한 번 누르면 시작하고 다시 누르면 현재 묶음을 완료한 뒤 중지합니다.
- 지정 횟수 실행: 입력한 횟수만큼 실행한 뒤 자동으로 중지합니다.

[저지연 입력]
- 대상 창이 이미 활성 상태이므로 매크로 시작 전 불필요했던 60ms 대기를 제거했습니다.
- 입력 시점에 대상 창을 직접 확인하므로 100ms 화면 상태 갱신을 기다리지 않습니다.
- 입력 실행은 키 감지 큐와 분리되어 누름 유지 대기가 다음 키 감지를 막지 않습니다.
- 안정 입력을 끈 일반 연타에서 1단계 바인딩을 적용하지 않는 키보드+클릭 조합은 한 번의 Windows 입력 요청으로 묶어 전송합니다.
- 퍼즈/안정 입력은 누름 유지와 단계별 대기를 사용하여 순차 전송합니다.
- 고정밀 Windows 대기 타이머를 재사용하고, 지원되지 않으면 기존 계열의 대기로 대체합니다.
- 입력 패킷은 캐시해 반복 중 배열 생성을 줄입니다. 실패 때만 해제용 패킷을 별도로 생성합니다.
- 반복 작업은 1ms 타이머 정밀도 요청과 상향된 작업 우선순위도 사용합니다.
- 실제 반응 시간은 키보드 폴링률, Windows 작업 상황, 대상 프로그램의 프레임률과 입력 처리 방식에도 영향을 받습니다.

[ESC 키 할당]
- 바인딩의 할당 키, 매크로의 실행 키와 1단계 키보드 출력에 ESC를 지정할 수 있습니다.
- 키 선택 중 ESC를 누르면 취소되지 않고 ESC 키로 저장됩니다.
- 좌표 입력 화면에서 ESC는 기존처럼 좌표 선택 취소로 사용됩니다.

[참고]
- 대상 창이 비활성화되어 있으면 일반 키 입력을 가로채지 않습니다.
- 대상 창이 비활성화되거나 RapidPoint가 종료되면 누름 유지 중인 마우스 버튼은 자동으로 해제됩니다.
- 매크로 실행 키와 좌표 바인딩 키는 서로 중복할 수 없습니다.
- 프로그램이 생성한 키 입력은 RapidPoint를 다시 호출하지 않도록 차단됩니다.
- 관리자 권한으로 실행 중인 프로그램에는 RapidPoint도 같은 권한으로 실행해야 할 수 있습니다.
- 일부 게임 및 서비스는 자동 입력을 금지합니다. 사용 전에 해당 서비스 정책을 확인하세요.
- 설정은 %LOCALAPPDATA%\RapidPoint\settings.json에 자동 저장됩니다.
